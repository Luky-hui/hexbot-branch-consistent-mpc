Legged locomotion in high-dimensional robots remains fundamentally difficult because the controller must optimize over nonlinear rigid-body dynamics, hybrid contact schedules, actuator limits, and geometry-dependent feasibility constraints within a short receding-horizon cycle. These challenges are amplified in hexapods, whose larger number of limbs increases contact redundancy, enlarges the decision space, and creates multiple joint-space realizations that may appear nearly equivalent at the task-space level. As a result, an optimizer can return a numerically plausible solution while still violating mechanism-level physical semantics.

This paper studies precisely such a failure mode in a six-legged robot controlled by OCS2-based model predictive control (MPC). During forward walking, we observed that the previous SQP pipeline could converge to a locally attractive but physically inconsistent tarsus branch. Although the resulting joint configuration remained close to the desired foot-space behavior, it belonged to the wrong mechanical branch for the left/right tarsus joints. A runtime branch-consistency guard could block these outputs after optimization, but this merely prevented catastrophic execution; it did not solve the underlying optimal control problem. The practical consequence was severe: frequent guard interventions, prolonged stagnation, and near-zero forward progress.

The central insight of this work is that branch consistency must be encoded at the solver level rather than enforced as a post hoc runtime correction. We therefore introduce a hard \emph{TarsusBranchConstraint} into the OCS2 problem definition and replace the previous SQP backend with an Interior-Point Method (IPM) solver that preserves this inequality structure during optimization. This design eliminates the physically invalid branch from the effective feasible set and thereby removes the hidden failure mode that previously dominated walking performance.

The contributions of this paper are threefold:
\begin{enumerate}
    \item We identify and diagnose a previously hidden failure mode in hexapod MPC, namely the convergence of a warm-started SQP pipeline to physically inconsistent tarsus branches despite apparently acceptable task-space behavior.
    \item We propose a solver-visible branch-consistency formulation, implemented as a hard \emph{TarsusBranchConstraint}, and show how switching to IPM restores true inequality enforcement in the receding-horizon optimization loop.
    \item We provide fully reproducible Isaac Sim experiments demonstrating that the proposed method eliminates branch-guard violations, recovers stable forward locomotion, and preserves real-time feasibility with sub-5-ms average solve time.
\end{enumerate}

More broadly, this work argues that safety in multi-legged MPC cannot be reduced to objective shaping or runtime filtering alone. When mechanism-level admissibility is not embedded in the optimization problem itself, local minima can become behaviorally deceptive. By explicitly constraining physical branch validity and solving the resulting problem with an inequality-faithful numerical method, we obtain a controller that is both more reliable and more scientifically interpretable.
